Web Scraper for Headlines & Quotes

Description

A Python web scraper that extracts quotes and author names from a website and saves the collected data into a JSON file.

Features

- Sends HTTP requests using the Requests library.
- Parses HTML using BeautifulSoup.
- Extracts quotes and author names.
- Saves extracted data in JSON format.
- Handles request errors.

Libraries Used

- requests
- beautifulsoup4
- json (Python standard library)

Installation

pip install requests beautifulsoup4

How to Run

python web_scraper.py

Output

The extracted quotes are saved in "quotes.json".
