# Interactive Calculator & Unit Converter

## Project Description

This is a beginner-friendly Python CLI program that performs basic arithmetic operations and unit conversions.

The program allows users to calculate addition, subtraction, multiplication, and division. It also supports kilometer-to-mile and Celsius-to-Fahrenheit conversions.

## Features

- Addition (+)
- Subtraction (-)
- Multiplication (*)
- Division (/)
- Kilometers to Miles conversion
- Celsius to Fahrenheit conversion
- Input validation using while loops
- Handles invalid inputs
- Simple and user-friendly command-line interface

## Technologies Used

- Python
- Conditional statements
- While loops
- Functions
- User input and output

## How to Run

1. Make sure Python is installed on your computer.
2. Open a terminal in the project folder.
3. Run the following command:

python calculator.py
