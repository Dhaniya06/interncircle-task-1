# Personal Expense Tracker with CSV

## Project Description

A beginner-friendly Python program to record and manage daily expenses using a CSV file.

## Features

- Add new expenses
- View all expenses
- Filter expenses by category
- Calculate category-wise expense totals
- Store expense data permanently in a CSV file

## Technologies Used

- Python
- CSV module
- File handling

## How to Run

Run the following command:

```bash
python expense_tracker.py
