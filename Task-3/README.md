# Number Guessing Game & Word Counter

## Project Description

This project contains two beginner-friendly Python programs: a Number Guessing Game and a Word Counter.

## 1. Number Guessing Game

The Number Guessing Game generates a random number between 1 and 100. The user has to guess the number, and the program gives hints such as "Too high" or "Too low" until the correct number is guessed.

### Features

- Generates a random number using the `random` module
- Accepts user guesses
- Provides too high / too low hints
- Counts the number of attempts
- Handles invalid input
- Displays the final result

## 2. Word Counter

The Word Counter reads text from a file and counts the total number of words. It also displays the frequency of each word.

### Features

- Reads text from a file
- Counts total words
- Displays word frequency
- Handles missing files
- Uses Python string processing and `Counter`

## Files

- `guessing_game.py` - Number Guessing Game
- `word_counter.py` - Word Counter program
- `sample.txt` - Sample text file for testing

## Technologies Used

- Python
- Random module
- File handling
- Regular expressions
- Collections Counter
